# дора хочет

изолированная статическая страница `/wishlist` в стиле основного сайта

- `data.json` — публичный снимок согласованных желаний из notion, обновлён 14 октября 2026
- `app.js` — поиск, фильтры, карточки, ссылки на отдельный подарок, локальный список выбора и копирование сообщения
- `style.css` — независимые стили с палитрой и шрифтами основного сайта
- без секретов, cookies, сторонней аналитики, публикации личных заметок или автоматических покупок
- «мой выбор» сохраняется только в браузере, не является общей бронью
- серверная бронь и автоматическая синхронизация с notion не подключены; изменения `data.json` публикуются через существующий git → vercel процесс
- фото — референсы; точные модели, цвета и комплектации согласуются отдельно
- стоковые фото: dayong tien (белая футболка), pavel danilyuk (стетоскоп), kenneth surillo (тату), pexels

основные страницы, crm, роутинг и настройки безопасности не меняются

проверка после публикации: workflow `wishlist public smoke`, отчёт и скриншоты в artifact `wishlist-evidence`
