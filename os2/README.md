# dashhkuns OS 2.0 — Quality Automation

Реальный GitHub-конвейер, не отдельная CRM и не замена действующим ChatGPT-автоматизациям.

## Что запускается

- PR: стандартные unit-тесты и read-only проверка **добавленных строк** на очевидные секреты. Значения никогда не выводятся.
- После попадания workflow в default branch: раз в 6 часов проверка доступности публичных страниц EBI и dashhkuns, HTTPS и ожидаемой идентичности. Ошибка отмечается красным статусом Actions; исправление происходит через проверенный PR, без auto-deploy.
- Dependabot еженедельно готовит PR с обновлениями GitHub Actions. Без автоматического merge.

## Что не покрывается

- Полноценное обнаружение всех ключей и уязвимостей. Для этого добавить аудит Betterleaks с закреплённым релизом после проверки лицензии/загрузки.
- Проверка отправки формы, доступов в CRM, попадания письма в Inbox, логов Telegram и реального Mac: нужны отдельные источники и тестовые события.
- Workflow на feature-ветке не означает, что cron включён. Планировщик активируется GitHub только после попадания файла в default branch.

## Локальный запуск

```bash
python3 -m unittest discover -s os2/tests -v
python3 os2/health_probe.py
# Для PR diff (из ветки с origin/main):
python3 os2/secret_guard.py --base <SHA_BASE>
```

Все проверки бесплатны как исходный код. Расходы GitHub Actions и hosting зависят от типа репозитория/действующих лимитов.
